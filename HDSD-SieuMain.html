1. Chọn Mẫu & File Bắt Đầu

Hệ thống có sẵn các mẫu chuẩn được tối ưu hóa cho từng thể loại tài liệu trong thư mục typst/. Bạn nên chọn file phù hợp nhất để copy và đổi tên bắt đầu soạn thảo:

Đường dẫn file mẫu Loại tài liệu phù hợp Đặc điểm nổi bật
typst/book.typ Sách/Tài liệu ngắn Gọn nhẹ, bố cục chuẩn, không rườm rà.
typst/sgk.typ Sách Giáo Khoa (SGK) Có đủ chu trình sư phạm: Khởi động, Khám phá, Luyện tập, Vận dụng...
typst/chuyende.typ Chuyên đề dài Chia theo: Phần -> Chương -> Dạng toán -> Phương pháp giải -> Ví dụ.
typst/bo-de.typ Tuyển tập bộ đề thi Nhiều đề song song, tự động gom đáp án và in bảng đáp án cuối mỗi đề.
typst/Beamer.typ Slides trình chiếu bài giảng Tích hợp Touying, hiệu ứng hiện dòng pause, bảng đáp án tự động.

2. Cấu hình Chung (`_config.typ` & Router)

Cấu hình tổng quản điều hành diện mạo và các chế độ ẩn hiện lời giải.

2.1. File _config.typ

Thường đặt ở thư mục chương (ví dụ sach/ham-so-chuong1/_config.typ) để ghi đè các cấu hình toàn cục:

#let EXAM_MODE = "dethi" // "dethi" (Ẩn lời giải) hoặc "loigiai" (Hiện lời giải)
#let IS_BOXED = true    // Bật/tắt tự động đóng khung cho tất cả vd, bt, tn, ds...
#let EXAM_SOL_COLOR = rgb("#0f4c81") // Màu sắc điểm nhấn lời giải

2.2. Router Tổng stexgv-doc

Sử dụng ở đầu file biên soạn để khai báo siêu dữ liệu của tài liệu:

#show: stexgv-doc.with(
  doc-type: "chuyende",        // "book" | "sgk" | "chuyende" | "bo-de" | "exam" | "research"
  title: "TÊN TÀI LIỆU",
  subtitle: "Mô tả ngắn phụ đề",
  author: "GV Nguyễn Văn Sang",
  theme-color: rgb("#0f4c81"),  // Màu nhấn chủ đạo
  margin: (x: 1.5cm, y: 1.5cm), // Tối ưu lề siêu tiết kiệm giấy
  show-cover: false,            // Hiện/ẩn trang bìa tự động
  show-outline: false,          // Hiện/ẩn mục lục tự động
)

3. Phân Cấp & Bộ Đếm Sách

Hệ thống hỗ trợ cấu trúc tiêu đề chặt chẽ tự động đếm số thứ tự.

Cú pháp lệnh Loại tiêu đề Hệ thống đếm
#part[Tiêu đề] Phần lớn PHẦN I, PHẦN II (Roman)
#chapter[...] Chương CHƯƠNG 1, CHƯƠNG 2
#lesson[...] / #bai Bài học BÀI 1, BÀI 2 (Kèm dải màu dài)
#topic[...] / #dang Dạng toán Dạng 1, Dạng 2 (Đánh số)
#section[...] / #muc Mục lý thuyết 1. Tiêu đề mục (Kèm viền chân)
#subsection[...] / #tieumuc Tiểu mục nhỏ 1.1. Tiêu đề (Kèm pill tròn nền nhạt)
#y[Tiêu đề] Ý nhỏ a) Tiêu đề

3.1. Các trang đặc biệt không đánh số

Sử dụng ở đầu hoặc cuối sách:

#loinoidau[ ... ]      // Lời nói đầu
#gioithieu[ ... ]      // Giới thiệu
#huongdansudung[ ... ]  // Hướng dẫn sử dụng
#muctieuchung[ ... ]    // Mục tiêu chung của giáo trình
#bangthuatngu[ ... ]    // Bảng thuật ngữ cuối sách
#tailieuthamkhao[ ... ] // Tài liệu tham khảo

3.2. Ép hoặc Reset Bộ đếm

Dùng khi muốn sang chương mới hoặc sang tệp tin mới không bị đếm chồng:

#resetchuong() // Đặt lại số chương = 1
#resetbai()    // Đặt lại số bài = 1
#resetvd()     // Đặt lại số Ví dụ = 1
#resetbt()     // Đặt lại số Bài tập = 1
#setbai(5)     // Ép bài tiếp theo là Bài 5

6. Câu Hỏi Đề Thi (TN / DS / TLN)

Tương thích 100% với cấu trúc đề thi trắc nghiệm khách quan mới THPT. Để sử dụng, ở đầu file hãy khai báo: #let (tn, ds, tln, tl) = exam-mode()

6.1. Trắc nghiệm 4 đáp án (MCQ)

Dùng #mcq hoặc #tn. Đáp án đúng được bọc bằng hàm True().

#tn(
  [Cho hàm số $y = f(x)$ có bảng biến thiên... Khẳng định nào đúng?],
  ([Cực đại bằng $2$], [Cực tiểu bằng $1$], True([Đồng biến trên $(0; 2)$]), [Nghịch biến]),
  loigiai: [Ta thấy trên khoảng $(0; 2)$ đạo hàm $y' > 0$ nên đồng biến.],
  cols: 2 // Ép chia thành 2 cột đáp án
)

6.2. Trắc nghiệm Đúng/Sai (TF)

Dùng #tf hoặc #ds. Nhập một mảng các phát biểu đúng/sai:

#ds(
  [Xét hàm số bậc ba $y = f(x)$. Đánh giá các mệnh đề sau.],
  (
    True([Hàm số có hai điểm cực trị.]),
    False([Đồ thị hàm số không có tâm đối xứng.]),
    True([Đạo hàm có hai nghiệm phân biệt.])
  ),
  use-table: false, // Có hiệu lực từ sang-math 1.0.4
  loigiai: [Mệnh đề a và c đúng. Mệnh đề b sai vì đồ thị bậc ba luôn đối xứng qua điểm uốn.]
)

6.3. Trả lời ngắn / Điền số (Short)

Dùng #tln hoặc #short. Cho phép in ra các ô vuông điền số.

#tln(
  [Tìm giá trị lớn nhất của hàm số trên đoạn $[-1; 2]$.],
  [$5$], // Đáp số đúng
  loigiai: [Tính đạo hàm, so sánh các đầu mút ta được giá trị lớn nhất là 5.]
)

6.4. Các tham số bổ trợ nâng cao cho câu hỏi

  • boxed: true | false: Ghi đè cấu hình toàn cục đóng khung riêng cho câu hỏi này.
  • lines: 5: Tạo 5 đường dòng kẻ chấm cho học sinh viết trực tiếp.
  • fig: [Hình vẽ]: Chèn ảnh minh hoạ / đồ thị Cetz.
  • fig-pos: "right" | "left" | "center": Vị trí đặt hình vẽ.
  • fig-width: 35%: Chiếm tỉ lệ bề ngang của câu hỏi.

7. Soạn Tuyển Tập Bộ Đề Thi

Ghép nhiều đề thi vào một tài liệu duy nhất (như chuyên đề luyện đề). Từng đề sẽ tự động tách số câu độc lập và gom đáp án.

7.1. Cấu trúc một đề độc lập #de(...)

#de(
  title: [Đề ôn tập số 01],
  department: "SỞ GD&ĐT HÀ NỘI",
  school: "TRƯỜNG THPT CHUYÊN",
  subject: "TOÁN - KHỐI 12",
  duration: "90 phút",
  code: "101",                  // Mã đề
  show-answer-key: true,        // Tự động in bảng đáp án cuối đề thi này
  reset-state: true,            // Tự động đặt lại câu hỏi về Câu 1
)[
  #exam-part([PHẦN I. Trắc nghiệm nhiều lựa chọn])
  #tn(...)
  #tn(...)
  
  #exam-part([PHẦN II. Trắc nghiệm Đúng/Sai])
  #ds(...)
]

7.2. Các khối phân tích đề thi

Hỗ trợ giáo viên lập cấu trúc ma trận trước hoặc sau khi thi:

  • #matran[...]: Khối biểu đồ ma trận phân bổ mức độ nhận thức của đề.
  • #dacta[...]: Bảng đặc tả chi tiết kiến thức từng câu hỏi.
  • #huongdancham[...]: Hướng dẫn phân bổ điểm cho câu tự luận.
  • #luuybode[...]: Lưu ý quy chế phòng thi hoặc cách làm bài.

8. Bảng Biến Thiên & Bảng Xét Dấu

Vẽ bảng biến thiên tự động bằng Cetz cực nhanh và mượt mà. Đảm bảo import thư viện trước khi dùng: #import "bbt.typ": *

8.1. Bảng Biến Thiên Cực Trị (`bbbt`)

#bbbt(
  var: $x$,            // Nhãn hàng 1
  der: $y'$,           // Nhãn hàng 2
  func: $y$,           // Nhãn hàng 3
  x-vals: ($-oo$, $-1$, $1$, $+oo$),
  d-signs: ( $+$, $0$, $-$, $0$, $+$ ),
  v-vals: ($-oo$, $3$, $-1$, $+oo$)
)
  • Vùng không xác định: Sử dụng shade: ((1, 2),) để gạch chéo vùng từ mốc x thứ nhất sang mốc x thứ hai.
  • Tiệm cận đứng (||): Nhập "||" vào mảng dấu d-signs và v-vals để tạo đường sọc không xác định kéo dài xuyên suốt.

8.2. Bảng Xét Dấu (`bxd`)

Vẽ bảng xét dấu nhanh cho đạo hàm hoặc nhị thức:

#bxd(
  var: $x$,
  func: $y'$,
  x-vals: ($-oo$, $-2$, $1$, $+oo$),
  f-signs: ($-$, $0$, $+$, $||$, $-$)
)

8.3. Bảng Tối Ưu (`bbt-opt`)

Chuyên dùng cho bài toán tối ưu hoá thực tế, chỉ xét trên một đoạn nhất định:

#bbt-opt(
  x-vals: ($0$, $x_0$, $oo$),
  d-signs: ($-$, $0$, $+$),
  v-vals: ($oo$, $0$, $oo$),
  is-min: true // true: dạng cực tiểu (\/), false: dạng cực đại (/\)
)

9. Trình Chiếu Slides (Beamer) Beamer Exclusive

Hệ thống tự động chuyển đổi đề thi thành slide trình chiếu chữa đề cao cấp bằng thư viện Touying. Toàn bộ cấu hình mẫu đặt ở file typst/Beamer.typ.

Cách trình chiếu một đề thi (Ví dụ: de-30.typ):
Bước 1: Mở file typst/Beamer.typ, cuộn xuống gần cuối và đổi lệnh import trỏ đến đề của bạn:
#import "dethi/de-30.typ": make-questions as _de
Bước 2: Chạy lệnh trong Terminal: npm run watch:Beamer (Hoặc npm run compile:Beamer).
File trình chiếu sẽ được sinh ra tại typst/Beamer.pdf.

9.1. Thiết lập màu sắc và cỡ chữ slide

Bạn chỉ cần mở file typst/Beamer.typ và chỉnh sửa trực tiếp các biến sau:

// ── Màu nền slide ────────────────────────────────────────
#let bm-bg-color = rgb("#f1f5f9")  // Sáng: #f1f5f9 | Tối: #0f172a
#let bm-math-color = rgb("#f108ca") // Màu phương trình toán học

// ── Cỡ chữ (Hệ thống tự co giãn theo Base Size) ────────────
#let bm-base-size = 24pt // CHỈ CẦN CHỈNH BIẾN NÀY ĐỂ PHÓNG TO/THU NHỎ TOÀN BỘ SLIDE
#let bm-text-size = bm-base-size * 1.15  // Text chung
#let bm-q-size = bm-base-size            // Câu hỏi
#let bm-opt-size = bm-base-size * 0.85   // Phương án A, B, C, D
#let bm-sol-size = bm-base-size * 0.75   // Lời giải
#let bm-table-size = bm-base-size * 0.75 // Bảng Đ/S

9.2. Hiệu ứng hiện từng dòng bm-lines

Dùng để trình chiếu giải thích bài, nhấp chuột đến đâu hiện dòng chữ giải thích đến đó:

#bm-lines(
  [Bước 1: Ta đặt ẩn phụ $t = 2^x$.],
  [Bước 2: Phương trình trở thành $t^2 - 3t + 2 = 0$.],
  [Bước 3: Suy ra $t = 1$ hoặc $t = 2$.]
)

9.3. In Bảng Đáp Án Slide và Kết Thúc

  • #print-answer-key(): Slide tự động lập bảng gom các đáp án đã khai báo trong đề.
  • #het: Slide kết thúc cảm ơn học sinh chuyên nghiệp.

10. Tiện Ích Toán Học & Mẹo Soạn Thảo

Các hàm bổ trợ tăng tốc gõ công thức toán học cực nhanh.

10.1. Tách các bước lời giải bằng #step

Đặt trong loigiai của ví dụ hoặc câu hỏi. Lệnh tự động vẽ dải phân bước bên trái đẹp mắt:

#vd([Giải bài toán...])[
  #step[Lập điều kiện xác định cho ẩn...]
  #step[Biến đổi đưa về cùng cơ số...]
]

10.2. Phóng to / Thu nhỏ phân số (dfrac & tfrac)

Mặc định khi bạn gõ $1/40$ trong ma trận hoặc hệ phương trình (cases), phân số sẽ tự động thu nhỏ lại cho vừa dòng (inline). Để điều khiển kích cỡ phân số, bạn có 3 cách:

  • Ép phân số to ra (giống \dfrac): Dùng hàm display(1/40) hoặc dfrac(1, 40).
  • Ép tất cả phân số trong file tự động to bự: Thêm dòng này vào đầu file đề thi của bạn:
    #show math.frac: math.display
  • Ép phân số nhỏ lại (giống \tfrac): Dùng tfrac(a, b) để có phân số nhỏ xíu lồng vào lũy thừa hoặc chỉ số, ví dụ: $y = x^tfrac(3, 4)$.
Lưu ý cực kỳ quan trọng về các lệnh Toán:
Để dùng được dfrac, cup, cap và các lệnh tắt mang phong cách LaTeX, ở ĐẦU file đề thi của bạn BẮT BUỘC phải có dòng:
#import "../math-sym.typ": *
(Tuyệt đối không được quên dấu : * ở cuối, nếu không hệ thống sẽ báo lỗi "unknown variable").

10.3. Hệ Phương Trình / Hoặc nhanh

Viết nhanh hệ ngoặc vuông hoặc ngoặc nhọn:

  • Dấu hệ và {: $heva(a, b)$
  • Dấu hệ hoặc [: $hoac(a, b)$

11. Chèn Hình Vẽ & Đồ Thị (Toàn Tập)

Hệ thống hỗ trợ 2 loại hình ảnh phổ biến nhất: Ảnh chèn từ file có sẵn (PNG, JPG, SVG) và Hình vẽ trực tiếp bằng lệnh (dùng thư viện Cetz). Dưới đây là mọi tình huống bạn có thể gặp phải.

11.1. Cấu trúc lệnh tạo hình ảnh cơ bản

Loại 1: Chèn từ file ảnh (Dùng hàm image)

Bạn chỉ cần tải file ảnh vào cùng thư mục hoặc tạo thư mục images/ và gọi hàm image. Tham số width giúp bạn chỉnh to nhỏ tuỳ ý:

#image("hinh-chop.png", width: 5cm)  // Chỉnh rộng 5cm
#image("images/do-thi.jpg", width: 40%) // Chỉnh rộng bằng 40% bề ngang trang

Loại 2: Vẽ trực tiếp bằng code Cetz (Dùng #cetz.canvas)

Tham số cốt lõi để phóng to/thu nhỏ toàn bộ nét vẽ và toạ độ là length:

#cetz.canvas(length: 1.5cm, { // Đổi 1.5cm thành 2cm hình sẽ to ra
  import cetz.draw: *
  line((0,0), (2,2)) // Vẽ đường thẳng
})

11.2. TÌNH HUỐNG 1: Chèn hình đứng độc lập giữa văn bản

Khi bạn gõ lý thuyết hoặc đang viết phần loigiai: [...], bạn muốn hình vẽ nằm ngay ngắn ở giữa trang sách. Khối #align(center)[...] sẽ là công cụ bọc bên ngoài tốt nhất.

Theo giả thiết, ta có hình minh họa sau:
#align(center)[
  // Bỏ hàm ảnh hoặc code cetz vào đây
  #image("hinh-minh-hoa.png", width: 60%)
]
Dựa vào hình trên, ta suy ra...

11.3. TÌNH HUỐNG 2: Chèn hình đính kèm câu hỏi trắc nghiệm (#tn, #ds)

Trong một bài thi, câu hỏi thường có cấu trúc: [Nội dung chữ] + [Hình vẽ bên phải] + [Các phương án A B C D bên dưới]. Để làm được điều này mà không phá vỡ bố cục tự động, bạn TUYỆT ĐỐI KHÔNG dùng `#align`. Hãy truyền hình vào tham số fig:.

Ví dụ dùng file ảnh:

#tn(
  [Cho hình chóp $S.ABC$ có đáy như hình bên. Tính thể tích:],
  ([$V=1$], [$V=2$], [$V=3$], [$V=4$]),
  fig: image("hinh-chop.png", width: 4cm), // Truyền thẳng hàm image vào đây
  fig-pos: "right", // Hình nằm bên phải câu hỏi chữ
  fig-width: 30%,   // Cột chứa hình chiếm 30% bề ngang trang
)

Ví dụ dùng code vẽ Cetz:

#tn(
  [Cho đồ thị hàm số như hình dưới. Tọa độ cực đại là:],
  ([$(0;2)$], [$(2;0)$], [$(1;1)$], [$(3;3)$]),
  fig: cetz.canvas(length: 0.8cm, {
    import cetz.draw: *
    // code vẽ đồ thị...
  }),
  fig-pos: "center", // Hình nằm chính giữa, BÊN DƯỚI nội dung câu hỏi
  fig-width: 100%,   // Cột chứa hình chiếm 100% bề ngang
)
Bảng giá trị của fig-pos:
  • "right": Hình nằm bên phải phần câu dẫn. Rất gọn gàng cho hình nhỏ.
  • "left": Hình nằm bên trái phần câu dẫn.
  • "center": Hình nằm chính giữa trang, phía trên 4 phương án A, B, C, D. Phù hợp cho đồ thị to ngang.

11.4. TÌNH HUỐNG 3: Các phương án A, B, C, D đều là hình vẽ (Code Cetz)

Nếu bạn muốn gõ code cetz để vẽ 4 đồ thị trực tiếp cho 4 phương án A, B, C, D, bạn chỉ việc đặt 4 khối cetz.canvas(...) vào đúng vị trí của 4 đáp án. Hệ thống sẽ tự động phát hiện mã lệnh vẽ và chuyển thành giao diện khung ảnh (Card layout) rất đẹp mắt.

#tn(
  [Đường cong nào dưới đây là đồ thị của hàm số $y = x^3 - 3x$?],
  (
    // Phương án A
    [#cetz.canvas(length: 0.5cm, {
      import cetz.draw: *
      line((-2,0), (2,0), mark: (end: ">")) // Trục hoành
      bezier((-1,-1), (1,1), (-0.5,1), (0.5,-1)) // Đường cong A
    })],
    
    // Phương án B
    [#cetz.canvas(length: 0.5cm, {
      import cetz.draw: *
      line((-2,0), (2,0), mark: (end: ">"))
      bezier((-1,1), (1,-1), (-0.5,-1), (0.5,1)) // Đường cong B
    })],
    
    // Phương án C (Đáp án đúng)
    True([#cetz.canvas(length: 0.5cm, {
      import cetz.draw: *
      line((-2,0), (2,0), mark: (end: ">"))
      circle((0,0), radius: 1)
    })]),
    
    // Phương án D
    [#cetz.canvas(length: 0.5cm, {
      import cetz.draw: *
      line((-2,0), (2,0), mark: (end: ">"))
      line((-1,-1), (1,1))
    })]
  ),
  opt-fig: true,       // Khuyên dùng: Ép hệ thống chuyển sang chế độ hình vẽ
  opt-fig-cols: 4,     // Chia thành 4 cột ngang nhau
)

14.3. Sử dụng #hw[...] trong nội dung

Sau khi khai báo handwriting-font, hàm #hw[...] tự động có sẵn khắp nơi trong file:

// Trong lời giải:
#meo[#hw[Nhớ công thức này! Đọc lại nhiều lần!]]

// Trong nội dung thường:
#hw[Học sinh làm bài vào đây]

// Trong câu hỏi:
#tn(
  [Tính giá trị biểu thức... #hw[(Gợi ý: nhớ công thức!)]], 
  ...
)
Lưu ý khi dùng font HP001 trong VSCode: Cần có typst.fontPaths: ["fonts"] trong file .vscode/settings.json (file này đã được cài sẵn). Khi compile từ terminal cần thêm --font-path fonts/ vào lệnh.

14.4. Khi không có handwriting-font

Nếu không khai báo handwriting-font (mặc định none), lệnh #hw[...] tự động chuyển sang in nghiêng thay thế — không gây lỗi.
