📄 Bài Tập Mẫu (iPad Study View)
Bài toán (Trích trong ảnh mẫu):
Giải phương trình: $$(x + 3)\sqrt{10 - x^2} = x^2 - x - 12$$
Lời giải:

Điều kiện xác định: \(10 - x^2 \ge 0 \iff -\sqrt{10} \le x \le \sqrt{10}\) (\(\approx -3.162 \le x \le 3.162\)).

Phương trình tương đương:

\((x + 3)\left[\sqrt{10 - x^2} - (x - 4)\right] = 0\)

• Trường hợp 1: \(x + 3 = 0 \iff x = -3\) (Thỏa mãn điều kiện).
• Trường hợp 2: \(\sqrt{10 - x^2} = x - 4\)
Điều kiện: \(x - 4 \ge 0 \iff x \ge 4\). Kết hợp với miền xác định \(x \le \sqrt{10} \approx 3.162\) suy ra mâu thuẫn, vô nghiệm!
💡 Kiểm tra bằng TABLE fx-580:
Nhập \(f(x) = (x+3)\sqrt{10-x^2} - (x^2 - x - 12)\).
Với \(x = -5, -4.655, -4.31, -3.965\) máy báo ERROR do nằm ngoài tập xác định (y hệt màn hình máy tính bên cạnh)!
