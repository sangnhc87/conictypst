Ví dụ nhanh:
Cấu hình BBT
Điền x, dấu y′, và giá trị y. Dùng: +oo = +∞, -oo = -∞, 0 = 0.
Ký hiệu đặc biệt: || = bất liên tục/gián đoạn, 0 = điểm cực trị.
Nhập cặp index cột (từ 0), vd: 1,2 để gạch từ cột 1 đến cột 2. Cột 0 = x[0] (-∞), cột 1 = x[1], v.v.

Mã Typst sinh ra
Tham chiếu macro bbtv2
Signature: 
#bbtv2(
  var: $x$,         // biến số
  der: $y'$,        // nhãn đạo hàm
  func: $y$,        // nhãn hàm số
  x-vals: (),       // mảng x (gồm cả -∞, +∞)
  d-signs: (),      // dấu: 2n-3 phần tử
  v-vals: (),       // giá trị y tại mỗi x-val
  shade: (),        // vùng gạch chéo: ((i,j),)
)
d-signs — quy tắc dài 2n-3:
Với n x-vals: [khoảng₀, tại_x₁, khoảng₁, tại_x₂, ..., khoảng_{n-2}]

v-vals — giá trị tại mỗi x-val:
• Đơn: $3$ hoặc $+oo$
• Nhảy (tiệm cận): ($+oo$, $-oo$) — giá trị trái, phải

shade: ((1, 2),) — gạch chéo từ cột 1 đến cột 2
