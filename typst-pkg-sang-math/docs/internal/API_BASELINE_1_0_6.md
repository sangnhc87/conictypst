# sang-math 1.0.6 API baseline

Source: the committed `typst-pkg-sang-math` tree at the start of the 1.1 work. `lib.typ` wildcard imports these modules; non-underscore names below are treated as public, including names that also appear in examples, docs, and templates. Each signature includes the 1.0.6 positional order and defaults. **Compatibility: MUST PRESERVE** for every listed name. This inventory is intentionally inclusive.

## Behavior contracts

- `tn = mcq`: accepts `(stem, options, correct: (), loigiai: none, mode: "dethi", ...)`; dictionaries from `True(body)` or `False(body)` carry their own `correct` flag. For a dictionary option, the separate `correct:` index tuple is ignored. Plain options use one-based indices in `correct:`. Answer state stores the **last** marked option as A–F or `?`.
- `ds = tf`: accepts `(stem, statements, loigiai: none, mode: "dethi", ...)`. A plain statement is false; `True(body)` is true. The legacy table and nine list/card styles keep the existing visibility rules and spacing.
- `tln = short`: accepts `(stem, answer, loigiai: none, mode: "dethi", ...)`; the answer box appears in non-`dethi` mode. `tl` accepts `(stem, loigiai: none, mode: "dethi", ...)` and prints writing lines by default.
- `exam-mode` returns bound `tn`, `ds`, `tln`, `tl`, `mcq`, `tf`, `short`; `exam-preset` maps `dethi`, `loigiai`, `compact`, `draft`, `beamer`, `slide`, `slides`, `answer`, and `twocol` profiles to the same question and template settings.
- Question numbering uses the `se-q-marker` and `se-q-reset` metadata selectors. `resetcau`, `setcau`, `exam-part(reset-counter: true)`, `num:`, and `resetexamstate` affect the next visible number. `resetexamstate` also clears the four answer metadata states.
- `print-answer-key` and `sang-omr-qr` read those metadata states. MCQ, true/false, short-answer, and written-response ordering, exam code, and QR payload must stay aligned.
- `book-palette` and `exam-template-names`/`book-template-names` expose existing theme names. Existing palettes, colors, and layout are preserved.
- `geometry.typ`, `geometry-2d`, `geometry-3d`, `bbt.typ`, and `math-sym.typ` are exported through the package root. The last wildcard imports may shadow earlier names; notably the 3D `vec` shadows the math-symbol `vec`.

## Baseline verification

With Typst 0.14.2, 29 of 30 package tests, examples, and the manual compiled before changes. `examples/exam-template-demo.typ` already failed because `$vec(a)$` resolves to the 3D coordinate constructor. The existing CI matrix covers Typst 0.14.0 and latest. Current examples under `examples/copy-ready` import older published `@preview` releases; the two top-level demos import local source.
